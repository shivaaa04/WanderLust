# 🌍 WanderLust

WanderLust is a full-stack travel listing web application inspired by Airbnb. It allows users to explore travel destinations, create and manage property listings, and share reviews with ratings. The project is built using Node.js, Express.js, MongoDB, Mongoose, EJS, and Bootstrap.

---

## ✨ Features

- 🏡 Create new travel listings
- ✏️ Edit existing listings
- 🗑️ Delete listings
- 🔍 View all travel listings
- 📄 View detailed listing information
- ⭐ Add ratings and reviews
- ✅ Server-side validation using Joi
- ⚠️ Custom error handling with Express
- 🔄 RESTful CRUD operations
- 📱 Responsive user interface with Bootstrap

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/shivaaa04/WanderLust.git
```

### Go to the project folder

```bash
cd WanderLust
```

### Install dependencies

```bash
npm install
```

### Start MongoDB

```bash
mongod
```

### Run the application

```bash
node app.js
```

or

```bash
nodemon app.js
```

### Open in Browser

```
http://localhost:3000
```
